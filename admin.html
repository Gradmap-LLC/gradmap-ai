CSV format

Required: title, event_date (YYYY-MM-DD only).

Optional: sub_info (free text), applicable_grades (comma-separated, e.g. "11,12"; blank = every grade).

Re-uploading the same title + event_date updates that event instead of creating a duplicate. A bad row is skipped and reported; it doesn't stop the rest.
